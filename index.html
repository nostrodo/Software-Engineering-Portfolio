Mitchell Flint — CS-499 Portfolio

Computer Science Capstone Portfolio

This portfolio documents the three enhancements I made to an application originally developed for CS-360. The original Android inventory application was converted into a Java console application for managing fictional medical claims, with additional work on data structures, databases, and security.

Professional Self-Assessment

Programming has been a passion of mine for many years, long before ever enrolling in school. My interest initially sprouted from a love of video games, where I eventually began to play around with making my own. I had initially started with code-free introductions into the process like with GameMaker Studio 2, but it wasn’t long before I was coding my games in engines like Unity and Unreal. Most of what I made back then barely worked, but I knew even then this was mostly due to knowledge gaps. Through school, I learned how to implement concepts like state machines, data structures, database communications, as well as many object-oriented principles that filled in those gaps. The school coursework also expanded my knowledge into concepts I knew nothing about prior, including security principles, network communications, several additional programming languages, and also how to implement it in a clean and maintainable way.

Much of what I learned has many applications beyond the classroom, some of which I’ve already been able to participate in real work environments. There were several courses going over corporate methodologies towards team development like both Agile and Waterfall. I was able to relate that to my existing office work in medical billing, where working as a team is essential, even if organized differently. I got to participate in a user acceptance testing session for a UiPath automation process that was being rolled out to the department. I’ve even started making helpful productivity tools in the office that are meant to assist my coworkers and cut down on time spent with repetitive processes. A PowerShell tool I had initially developed for myself had attracted interest from management, introducing challenges of accommodating for a broader group of users, like developing for stakeholders.

The artifact I have chosen for my Capstone project was specially crafted to unify my work experience and developer journey. It began as a warehouse inventory android application, one of several options I had for the CS-360 class. I had picked that in order to draw on my experience as a material handler in a factory, which involved a significant amount of documenting inventory movements. For the first enhancement, I pulled it out of Android Studio to run on the console, and began converting it to a small-scale medical claim manager, relating it to my current work in the medical field. The second enhancement incorporated algorithms and data structures by introducing a fictional medical code catalog with a CSV file, and utilizing a HashMap for quick code lookups. The third focused on databases and especially security, by incorporating password hashing and permanent claim storage. With each enhancement, I have taken an existing android application and evolved it into a demonstration of my abilities with software development, with each step motivated by my experiences.

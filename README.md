## Projects

### Android Inventory App

A mobile inventory management application built for Android using Java and SQLite. The app allows users to create an account, log in, enable or reject SMS permissions, and manage inventory records with item names, quantities, and locations.

**Technologies used:** Java, Android Studio, SQLite, Android SDK

**Key features:**
- User account creation and login
- Local SQLite database storage
- Add, edit, view, and delete inventory items
- Inventory table display
- SMS permission prompt before entering the inventory screen

### MongoDB Animal Shelter Dashboard

An interactive Python dashboard built with Dash, JupyterDash, MongoDB, Pandas, Plotly, and Dash Leaflet. The dashboard connects to an animal shelter database, filters rescue candidates by category, displays matching records in a data table, visualizes breed distribution with a chart, and maps selected animal locations.

**Technologies used:** Python, MongoDB, PyMongo, Dash, JupyterDash, Pandas, Plotly, Dash Leaflet
